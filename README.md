# Palmira VR

Palmira VR is an immersive Virtual Reality application developed for cultural heritage education and enhancement, with a specific focus on the Roman Theatre of Palmyra.

The experience allows users to explore a virtual reconstruction of the monument and take part in different interactive and educational activities.

## Repository contents

The repository contains the Unity project of the application:

- `Assets/`
- `Packages/`
- `ProjectSettings/`

Folders automatically generated by Unity, such as `Library`, `Temp`, `Logs`, and `obj`, are not included.

## Requirements

The project was developed using:

- **Unity 2022.3.62f3**
- **Android** as the build platform
- compatible Meta Quest headsets

## Opening the project

To open the project:

1. download or clone the repository;
2. open Unity Hub;
3. select the `Unity_Project_PalmiraVR` folder;
4. open the project using the correct Unity version;
5. wait for Unity to complete the asset import process.

On the first launch, Unity will automatically recreate the `Library` folder, so opening the project may take several minutes.

## Android build

To create a new build of the application from Unity, make sure that **Android** is selected as the target platform.

In Unity:

`File → Build Settings → Android → Switch Platform`

You can then generate the APK by selecting **Build**.

## APK

A compiled and working version of the application is available in the **Releases** section of the repository.

The APK can be installed on a Meta Quest headset with Developer Mode enabled.
